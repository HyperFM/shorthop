SHORTHOP – UI POLISH UPDATE (v1.0)

GOAL  
Simplify interface to match the ease-of-use of apps like Uber, Lyft, and DoorDash.  
Focus on one main action per screen and reduce visual clutter.

------------------------------------------------------------

GLOBAL UI RULES

1. Every screen should have ONE primary action.
2. Limit color palette:
   - Primary: #22C55E (green)
   - Accent: #F97316 (orange)
   - Neutral: #F3F4F6 / #6B7280
3. Reduce text explanations everywhere.
4. Use rounded cards (16px radius).
5. Increase button size (minimum height: 56px).
6. Reduce icon colors to match palette.
7. Increase whitespace between sections.
