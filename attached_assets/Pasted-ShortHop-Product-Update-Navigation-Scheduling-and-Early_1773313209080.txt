ShortHop Product Update – Navigation, Scheduling, and Early Network Experience

Goal  
This update improves clarity, highlights scheduled shared routes (which are the core strength of ShortHop), and makes the early network feel active and engaging for new users.

The design should remain sleek, simple, and modern—similar in clarity to major ride apps—but with ShortHop’s unique focus on shared routes and scheduled commuting.

Schedule Feature (New Core Tab)

Add a new Schedule tab where users can create recurring trips.

The schedule system should allow users to:

• Select days of the week (Mon–Sun)  
• Choose starting location  
• Choose destination  
• Set a time window (example: 7:30–8:00 AM)  
• Optionally enable return trips  

Schedules must be editable anytime so users can adjust their weekly travel.

This helps the system match users who regularly travel the same routes.

Live Activity Indicator

Add a small activity section showing current network movement.

Examples:

• 2 riders traveling Richmond Rd this morning  
• 1 driver heading toward downtown  
• 3 new members joined today  

This helps the platform feel active even during early growth.

---

Hop Button (Primary Action)

The Hop button should represent requesting a ride immediately.

When tapped, it opens the ride search interface.

Optional micro-interaction  
Add a small bounce or pulse animation when the Hop button is pressed to make the interface feel responsive.

Keep animation subtle and smooth.

---

Visual Navigation Polish

Improve the visual feel of the bottom navigation bar while keeping the design sleek.

Suggested improvements:

• Thin separator line above the navigation bar  
• Subtle highlight when an icon is active  
• Maintain the ShortHop color flow (blue → green → orange)

The design should remain minimal and not overly animated.

---

Founding Member Progress

Keep the Founding Member progress indicator on the Home screen.

This helps early users see that the network is being built in real time.

The goal is to show that users are joining and participating together.

---

Design Goals

This update should achieve:

• clearer navigation  
• stronger emphasis on scheduled routes  
• improved onboarding for new users  
• a sleek modern interface  
• visible network growth  
• a stronger sense of community momentum

The interface should stay clean, simple, and intuitive while highlighting ShortHop’s unique shared-route system.
