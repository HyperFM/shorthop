First-Time Welcome Screen (Intro Animation)

ShortHop should include a first-time welcome animation that only plays the first time the user launches the app after installing.

Animation sequence:

• Character drives across the screen  
• Honk beat soundtrack plays  
• Text appears: “Jump, skipping a hop.”  
• Animation fades into the app home screen

Animation rules:

• Length: approximately 9 seconds  
• Animation should only play once per install  
• App should load in the background while animation plays  
• Allow tap to skip animation

File:

ShortHop_WelcomeIntro.mp4

Audio included in the video.

────────────────

Quick Splash Screen (Normal Launch Screen)

After the first launch animation has already been seen, the app should use a quick splash screen on future launches.

Splash screen design:

• White background  
• ShortHop logo centered  
• Optional subtle fade or small logo animation

Rules:

• Duration: 1–2 seconds maximum  
• Appears every time the app opens after first launch  
• Must be fast and lightweight

File name:

ShortHop_QuickSplash.png

Launch logic:

If user has never opened app → show Welcome Intro  
If user has opened app before → show Quick Splash Screen

Developer implementation example:

hasSeenWelcomeAnimation = true

Driver Approaching Notification (Auto-Hop Alert)

When a driver is approaching the rider’s corridor or pickup location the rider must be notified.

This notification is essential for Auto-Hop schedules.

Purpose:

Alert the rider that their driver is nearby so they can step outside.

Notification triggers when driver:

• enters nearby corridor zone  
• is within approximately 200–300 meters

Sound file:

ShortHop_DriverApproaching_Alert.wav

Notification message example:

“Your driver is passing nearby and heading your direction.”

Notification behavior:

• sound alert  
• vibration  
• push notification

⭐ Final Stability Testing

Replit should perform edge-case testing:

• weak internet connection  
• GPS delay  
• app reopening after background  
• ride cancellation mid-trip  
• notification delivery under low signal  

These issues are the most common causes of early crashes.
